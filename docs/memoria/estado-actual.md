## Hallazgos priorizados
- **Defecto `null → 0` en notas (2026-11-16).** `CalificacionesService::matrizNotas()` usa `$calificacion ? (float) $calificacion->nota : null`, así que una fila con `nota = null` se muestra como `0`; `notasFinales()` tiene el mismo riesgo. Pendiente de autorización para corregirlo.
- **Sin prevención de duplicados en `evaluaciones` (2026-11-16).** No hay unique `(grupo_id, nombre, tipo)` y `GrupoNotas::agregarEvaluacion()` bloquea P1–P4/A solo con coincidencia exacta (sensible a mayúsculas). El supuesto duplicado de P1 no se reprodujo en la base configurada y el ID 3 no existe; no se modificaron datos.
- **Limitación de concurrencia PostgreSQL (2026-11-13).** Las pruebas actuales usan SQLite en memoria (`phpunit.xml`). La concurrencia real y el comportamiento de `lockForUpdate()` en PostgreSQL no han sido comprobados. Sigue siendo una limitación pendiente de validación.
